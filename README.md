Burrow Dash, day one vs day seven: a 24-second vertical video cutting between the same tiny agent-built game on the day it was made and after a week of daily updates — same map, same start, visibly more going on the second time. Day one is one gem, one beetle, no HUD; day seven is eight gems, five beetles, particles, a score and combo HUD, and a power-up star. The camera never moves, so the change is the whole story. It closes on the newer build being played, an invitation to start yours at make.fun, and make.fun's referral end card. The video is posted publicly on TikTok; `VIDEO.json` names it.

The game itself is in this repository: open `game.html` in a browser to play it (arrow keys or WASD steer the mole), and `game.js` holds the deterministic sim that rendered both builds — the same game-time in each build is the identical moment.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
